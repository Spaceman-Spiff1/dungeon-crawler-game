# Roadmap

## Milestone 1

- Create a character in Python
- Save it to SQLite
- Load it back
- Add a test for the round trip

## Milestone 2

- Add a very small Flask web page
- Submit a character form
- Save through the backend only
- Display the created character

## Milestone 3

- Add user accounts or managed auth
- Enforce ownership checks
- Prevent one user from viewing another user's character

## Milestone 4

- Add inventory and equipment
- Recalculate derived stats from gear
- Keep all item ownership checks on the backend

## Milestone 5

- Add encounters, enemies, and loot
- Log important state changes
- Add more tests around game rules

## Milestone 6

- Deploy to Cloud Run manually
- Add secrets handling and billing alerts
- Add GitHub to GCP integration only after local confidence is high

## Milestone 7

- Containerize the app for learning
- Practice GKE in a tiny temporary cluster
- Tear the cluster down after practice
